# Πλακωτό – Web Εφαρμογή (Client–Server)

## Περιγραφή
Η εφαρμογή υλοποιεί το επιτραπέζιο παιχνίδι **Πλακωτό** ως διαδικτυακό παιχνίδι δύο παικτών, ακολουθώντας **client–server αρχιτεκτονική**. Όλοι οι κανόνες του παιχνιδιού (ζάρια, κινήσεις, διπλά ζάρια, πλάκωμα, ανίχνευση νίκης) ελέγχονται **αποκλειστικά στον server**, ενώ ο client είναι υπεύθυνος μόνο για την απεικόνιση και την αποστολή αιτημάτων.

Η υλοποίηση είναι συμβατή με το πρότυπο που χρησιμοποιείται στα παραδείγματα του μαθήματος (ADISE), επαναχρησιμοποιώντας τη δομή `players`, `game_status` και REST-like endpoints.

---

## Χαρακτηριστικά
- Δύο παίκτες (Λευκά / Μαύρα)
- Server-side έλεγχος κανόνων (χωρίς cheating)
- Ρίψη ζαριών με υποστήριξη **διπλών ζαριών**
- Πλάκωμα (χωρίς χτύπημα)
- Υποχρεωτική αλλαγή σειράς όταν εξαντληθούν τα ζάρια
- Ανίχνευση νίκης (win detection)
- REST-like API με ανταλλαγή δεδομένων σε JSON

---

## Αρχιτεκτονική

### Client
- HTML / CSS / JavaScript (jQuery)
- Δεν υλοποιεί κανόνες παιχνιδιού
- Επικοινωνεί με τον server μέσω AJAX

### Server
- PHP
- MySQL
- Υλοποιεί:
  - κανόνες Πλακωτού
  - διαχείριση παικτών
  - κατάσταση παιχνιδιού
  - έλεγχο εγκυρότητας κινήσεων

## Βάση Δεδομένων

### Πίνακας `players`
| Πεδίο | Τύπος | Περιγραφή |
|------|------|-----------|
| piece_color | ENUM('W','B') | Χρώμα παίκτη |
| username | VARCHAR | Όνομα παίκτη |
| token | VARCHAR | Αναγνωριστικό σύνδεσης |
| last_action | DATETIME | Τελευταία ενέργεια |

### Πίνακας `game_status`
| Πεδίο | Τύπος | Περιγραφή |
|------|------|-----------|
| status | ENUM | not active / initialized / started / ended |
| p_turn | ENUM('W','B') | Σειρά παίκτη |
| result | ENUM('W','B') | Νικητής |

### Πίνακας `board`
| Πεδίο | Τύπος | Περιγραφή |
|------|------|-----------|
| id | INT | Primary key |
| pos | INT | Θέση (1–24) |
| piece_color | ENUM('W','B') | Πούλι |

## Τεκμηρίωση API

### Login Παίκτη
```
POST game.php?action=login
```
**Παράμετροι:** `username`, `color`

### Ανάκτηση Κατάστασης
```
GET game.php?action=state
```

### Ρίψη Ζαριών
```
POST game.php?action=roll
```
- Αν τα ζάρια είναι ίδια → δημιουργούνται 4 ίδια ζάρια

### Εκτέλεση Κίνησης
```
POST game.php?action=move
```
**Παράμετροι:** `src`, `dest`

### Reset Παιχνιδιού
```
POST board.php
```

## Κανόνες Πλακωτού (Υλοποίηση)
- Η κίνηση επιτρέπεται μόνο αν η απόσταση ισούται με διαθέσιμο ζάρι
- Σε διπλά ζάρια ο παίκτης παίζει τέσσερις φορές
- Δεν επιτρέπεται χτύπημα αντιπάλου (μόνο πλάκωμα)
- Η σειρά αλλάζει μόνο όταν εξαντληθούν τα ζάρια
- Νίκη όταν ένας παίκτης δεν έχει πλέον πούλια στο ταμπλό
